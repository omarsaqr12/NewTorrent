# Testing and interoperability

## Automated tests

```sh
python -m pip install -e ".[dev]"
python -m ruff check .
python -m compileall -q app tools tests benchmark.py
python -m unittest discover -s tests -v
python -m tools.swarm
```

The local CPython 3.11.1 run on Windows passed all 51 tests, lint and compilation.
The installed CLI also passed help, decode and metainfo smoke checks. Peer discovery,
handshake and piece-download commands are exercised as subprocesses against the
local swarm. The demo verified 1,048,593 bytes from two complementary TCP peers.

| Suite | Coverage |
|---|---|
| `test_client.py`, `test_wire_regressions.py` | Codec, metainfo, handshake, framing, piece integrity and command regressions |
| `test_scheduler.py` | Rarity counts, ownership, release, corruption attribution, parser limits and UDP retry timing |
| `test_session.py` | Bitfield padding/order, HAVE bounds, late responses, cancellation and commit-once behavior |
| `test_swarm.py` | Real TCP/HTTP/UDP transport, faulty peers, tracker failover, interruption/resume, publication and resource bounds |
| `test_properties.py` | Generated canonical codec roundtrips and arbitrary multi-file boundaries |

Real-socket cases include fragmented/coalesced messages, reordered blocks,
choke/unchoke, absent initial bitfields, later HAVE announcements, duplicate replies,
corrupt and stalled peers, subprocess termination, damaged checkpoints, changed or
missing staged data, symlink escapes, collisions, disk errors and lock release.
Small monotonic deadlines and deterministic payloads keep fault tests bounded.

The [CI workflow](../.github/workflows/tests.yml) runs lint, compilation, CLI checks,
the suite and the local demo on Linux Python 3.10/3.12/3.13 and Windows Python 3.11.
Performance benchmarks run separately.

## Independent seed

```sh
python -m pip install -e ".[interop]"
python -m tools.interop
```

The recorded check uses libtorrent 2.1.1.0 as an independent seeding session on
loopback TCP. DHT, LSD, UPnP, NAT-PMP and uTP are disabled, and peer discovery is
explicit. NewTorrent downloaded and verified all 1,048,593 generated bytes.
[interop.json](interop.json) records the version, settings and transfer counters.
This check covers the local v1 TCP exchange; public swarms and other client versions
need separate compatibility testing.

## Full local check

```sh
python -m pip install -e ".[dev,bench,interop]"
python -m tools.validate
```

The runner checks dependencies, lint, compilation, the installed CLI, tests, demo,
interoperability and regeneration of retained benchmark summaries. Logs and the
environment snapshot are written to the ignored `.validation/` directory.

Kernel locking and process-kill recovery are tested on the local filesystem.
Network-filesystem locking and device power-loss behavior remain untested. Blocking
DNS, HTTP or filesystem calls can delay cleanup; see [the design notes](design.md)
for shutdown and durability boundaries.
